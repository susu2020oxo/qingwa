# 青蛙吞噬 · Frog Devour

Minecraft **Java 版 1.21.10 / Fabric** 模组源码。进入世界就成为原版温带青蛙，默认按 **R** 吐舌头吞噬生物，按 **F5** 查看模型。按键可在「选项 → 控制 → 按键绑定 → 青蛙吞噬」修改。

**完整编译与 224 项成长/吞噬容量检查已通过，尚未进行实际游戏测试。** 构建记录见 `BUILD-STATUS.md`。

## 玩法与成长

| 青蛙体型 | 可吞噬的代表生物 | 原版青蛙模型倍数 | 吞噬距离 | 一次吞噬容量 |
| --- | --- | --- | --- | --- |
| 小型 | 鸡、鳕鱼、鲑鱼、河豚、热带鱼、1 格史莱姆、蠹虫、末影螨等 | 1 倍 | 6 格 | 1 只小型 |
| 中型 | 解锁羊、牛、猪、村民、僵尸等 | 2.5 倍 | 9 格 | 1 个目标 |
| 大型 | 解锁铁傀儡、骆驼、劫掠兽、马、嗅探兽等 | 6 倍 | 14 格 | 最多 9 只小型 / 3 只中型 / 1 只大型 |
| 巨型 | 解锁监守者、末影龙、凋零 | 14 倍 | 40 格 | 最多 27 只小型 / 9 只中型 / 3 只大型 / 1 只首领 |

大型和巨型可以向前方多个目标同时伸出多根粉红舌头，也可以混合吞噬，例如大型一次吃 1 只牛和 6 只鸡。

- 小型生物 = **1 食量**；中型 = **3 食量**；大型 = **9 食量**；首领 = **27 食量**。
- 小型 → 中型：吃 10 只小型，即增加 **10 食量**。
- 中型 → 大型：再吃 10 只中型，或 30 只小型，即再增加 **30 食量**。
- 大型 → 巨型：再吃 10 只大型，或 30 只中型，或 90 只小型，即再增加 **90 食量**。
- 三个升级节点的累计食量为 **10 / 40 / 130**；小目标永远能积累进度，零头保留。
- 巨型为最高等级，仍可继续吞噬。

屏幕经验条上方显示体型、原版模型倍数、当前阶段食量与升级进度。成长会同时改变模型、碰撞箱和视角高度。巨型碰撞箱约为 **7 × 7 格**，需要宽敞空间；请在开阔地升级或使用测试指令。

吞噬判定和成长奖励由服务端处理。需要靠近并瞄准目标，墙壁会阻挡舌头。小型、中型需要精准瞄准；大型、巨型可捕食前方约 100° 范围内的多个目标。每次按 R 有约 1.2～2 秒冷却，舌头动画约 0.6 秒。

食量保存到玩家存档，退出重进、死亡重生和更换维度后保留。多人游戏中所有玩家均为青蛙；服务端和客户端都需要安装本模组及 Fabric API。

## 在自己的电脑生成 JAR

需要 **JDK 21**（包含 `java` 和 `javac`）以及可访问 Fabric Maven、Mojang 和 Maven Central 的网络。只安装 JRE 不够。

Windows：解压完整工程后，双击 **`build-mod.bat`**。

macOS / Linux：

```sh
sh build-mod.sh
```

也可以直接在工程目录运行：

```sh
# Windows
gradlew.bat build

# macOS / Linux
sh gradlew build
```

构建成功后，安装 **`build/libs/frog-devour-1.0.0.jar`**。名称中带 `sources` 的文件是源码包，不能作为游戏模组安装。

`.github/workflows/build.yml` 会在 `main` 分支代码更新后自动编译、检查并发布到 `downloads` 分支，也可以从 GitHub Actions 手动运行。

## 安装

1. 在启动器中创建 **Minecraft Java 版 1.21.10** 实例，安装 **Fabric Loader 0.17.3 或更新版本**。
2. 下载适配 **1.21.10** 的 **Fabric API 0.138.4+1.21.10 或更新兼容版**。
3. 将 Fabric API 与编译生成的 `frog-devour-1.0.0.jar` 放入这个实例的 `mods` 文件夹。
4. 启动游戏，进入世界。默认立即变为小青蛙，按 F5 查看，瞄准鸡等小生物按 R。

不要放入 Forge / NeoForge 实例，也不要把它当作 1.21.1、1.21.4 或基岩版模组。

## 指令

- `/frog`：查看自己的体型和累计食量。
- `/frog stage 1`：小型；`2` 中型；`3` 大型；`4` 巨型。
- `/frog reset`：清空自己的食量并回到小型。

`stage` 和 `reset` 需要开启作弊或具有 2 级管理员权限。它们只影响执行者。

## 行为说明

- 吞噬只针对生物，不针对其他玩家、盔甲架、掉落物或船。
- 无敌、乘坐中或带乘客的生物不会成为目标。
- 史莱姆按实际大小分为小、中、大；吞噬后不产生分裂。
- 整只吞下的生物不产生普通死亡掉落，也不结算普通战斗击杀奖励；吞噬补充饥饿值。
- 吞噬真实末地战斗中的末影龙时，会调用原版屠龙完成逻辑，处理出口、龙蛋和折跃门；不会播放完整原版屠龙死亡动画或掉落屠龙经验。
- 使用原版温带青蛙模型和纹理；模型来自游戏资源，没有打包 Minecraft 的模型或纹理文件。
- 第三人称保留青蛙外形，不显示人形盔甲、披风和手持物；物品功能仍按玩家操作工作。第一人称隐藏人形手臂。

## 开发依赖

Minecraft 1.21.10、Yarn 1.21.10+build.2、Fabric Loader 0.17.3、Fabric API 0.138.4+1.21.10、Fabric Loom 1.11.8、Gradle 8.14.3、Java 21。已附带 Gradle Wrapper，并固定 Gradle 分发文件的 SHA-256。

成长数值在 `GrowthRules.java`，猎物分类在 `PreyClassifier.java`，多目标容量在 `FeedingBudget.java`，吞噬距离、舌头数量和冷却在 `GrowthRules.Stage` 中调整。
