青蛙吞噬 v1.0.2
适用 Minecraft Java 版 1.21.10 + Fabric。
将 JAR 放入该游戏实例的 mods 文件夹，并安装适配 1.21.10 的 Fabric API 0.138.4 或更新兼容版本。
进入世界即为小青蛙，R 键吞噬，F5 查看青蛙模型。
最大体型为原版青蛙 1.8 倍；四档血量为 3/6/10/15 颗心。
青蛙按小型、中型、大型、巨型成长；大型开始支持多舌头。
青蛙永久水下呼吸，所有体型均不会因缺氧窒息。
Iris 默认 R 键也是重载光影；本版在按键与吞噬重合时，仅在青蛙游戏中拦截重载，不改你的按键设置。
请删除旧版 JAR，只保留此版本，联机时服务端和客户端一起更新。
